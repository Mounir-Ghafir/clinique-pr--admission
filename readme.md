Système de Pré-admission Clinique

Description

Application web de gestion des demandes de consultation pour une clinique médicale. Ce système permet d'enregistrer, visualiser et gérer les demandes de pré-admission des patients de manière simple et efficace.




Fonctionnalités

Principales caractéristiques

. Formulaire de demande : Enregistrement des informations patient (nom, prénom, téléphone, email, motif, date souhaitée)
. Validation des données : Vérification des champs obligatoires avant soumission
. Stockage local : Sauvegarde automatique des demandes dans le navigateur (localStorage)
. Liste paginée : Affichage des demandes avec pagination (5 demandes par page)
. Suppression : Possibilité de supprimer des demandes individuelles
. Interface responsive : Compatible mobile, tablette et desktop
. Messages de confirmation : Retour visuel lors de l'ajout ou des erreurs




Technologies utilisées

. HTML5 : Structure de la page
. CSS3 : Stylisation et design responsive
. JavaScript (Vanilla) : Logique applicative
. localStorage : Stockage des données côté client
